# Su-35S 하부·도색·비행 시험 수정

작업 시작: 2026-10-30 **16:13:29 KST**. 최종 수정·검토 확인: **17:04:02 KST**. 게시 전에 50분 이상 작업했다.

하부 외피를 다시 대조해 잘못 제외했던 원본 외피 조각을 복구하고, 배기부 교체 시 복부 안정판이 삭제되지 않도록 절단 범위를 제한했다. 하부 전용 시점과 조명을 추가하고, 하부로 회전할 때 바닥을 숨긴다. 데스크톱에서는 캔버스 높이를 화면에 맞추고 제어 패널만 스크롤해 기체 끝부분이 화면 밖으로 밀려나지 않게 했다.

도색은 [52번/RF-81719의 사진](https://commons.wikimedia.org/wiki/File:Russian_Air_Force,_RF-81719,_Sukhoi_Su-35S_(49581740157).jpg)을 기준으로 밝은 청회색 바탕, 위장 경계, 기수와 반사 방지 부분, 번호·등록번호·국기·별 표식을 재구성했다. 기존 Su-27 도색 색상 대신 중립 기체 좌표의 도색을 사용하고 원본 UV 아트는 미세한 표면 디테일에 활용한다. 사진에 드러나지 않는 면의 위장 경계는 재구성이다.

`su35-flight.html`은 같은 외형을 사용하는 독립 비행 시험이다. 양력·항력·중력·고도별 추력, 엔진 지연, 연료 소모, 착륙장치 전개, 추력편향 반작용과 비행제어를 계산한다. 조종면과 노즐을 계산 상태에 연결했다. [계수·제원·구현 범위](../su35-flight-model.md)를 명시했으며 기존 전투 모드의 다른 기체 비행 모델을 Su-35로 표시하지 않는다.

수정과 확인 과정에서 고속 가속 중 추력의 수직 성분 때문에 발생한 트림 오차, 비행 중 추적 카메라가 뒤처지는 문제, 렌더 주기에 따라 속도 보호 계산이 달라질 수 있던 부분을 수정했다. 하부·도색·조종·모바일 화면을 다시 렌더해 확인했다.

검증:

- 하부 동체·나셀 17개 교차 지점과 흡입구 18개 시선 검사, HUD 유리 간섭 검사, 가동 조종면, 15.3 × 5.9 × 21.9m 치수, 기존 13개 기체.
- 대기·추력 수치, 동압에 따른 양력, 실속과 항력 증가, 최대 질량, 엔진 지연·연료·착륙장치 전개, TVC 반작용, 1G 트림, 상승·롤·요 반응, 30/120Hz 동일 궤적, 속도 보호 및 12개 기동 시나리오.
- 외형: 8개 시점, 5개 가동부, 키보드·포인터, PNG 저장, 390px 모바일 화면과 기체 트리 진입.
- 비행: 키보드 피치, 추력·착륙장치·TVC, 일시정지·초기화, 카메라 추적, 실제 모바일 터치 이벤트에 따른 롤 반응. 페이지·셰이더 오류 없음. 모바일은 Chromium 에뮬레이션이다.
- 내려받는 소스만으로 재생성했을 때 위치·법선·메타데이터와 원본 텍스처가 일치한다. Blender UV 세분화에는 최대 0.000011의 차이가 있었으며 2K 텍스처에서 0.03픽셀 미만이다. 배포 파일 자체는 해시로 검증한다.
